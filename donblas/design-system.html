Findings07 notes

Does it repurpose?

  1. The alternating rhythm

    Label block and specimen trading sides down the page is the strongest idea in the reference, and it costs the system nothing. It reads as editorial rather than dashboard, which suits a system whose components are page blocks first and widgets second. Donblas already ships Split-Content in three alignments — this is that component, used at a slower pace.

  2. The radius and shadow language

    The reference's floating cards land almost exactly on radius/4xl at 18px desktop, and the soft triple-layer shadow sits comfortably next to the system's existing card treatment. Nothing had to be invented.

  3. The logo construction plate

    A centred mark with side labels and a spec row underneath is the right frame for this system, but the reference's content does not transfer: Verde's mark is drawn on an 8pt circle grid, so its plate can honestly claim GRID 8pt / RADIUS 24px / GEOMETRY circular. The Donblas mark is four boolean vector shapes with no underlying construction, so the grid above is illustration, not derivation. The plate is kept and the labels changed to what is true — ratio, radius, geometry organic, five colourways. A construction plate that invents a grid is worse than none.

  4. The font system plate

    This is the strongest borrow of the three. A giant specimen with the weight list stacked beside it, a ghost Aa behind and a size ruler underneath maps directly onto how this system actually declares type — nine size steps and two weights, all as variables. Setting both families at display size side by side also makes the substitution problem visible rather than buried in a footnote.

  5. Semantic up and down

    The reference leans on green for good and implies red for bad. Donblas ships eleven blues, eleven mauves, eleven neutrals and exactly one semantic colour: error red. There is no positive. The shipped screens above never need one, because a marketing site has no state to report — but the moment this system carries the product, a rising cost and a falling risk both have to come out of the blue ramp. If this content model ships, the system needs a declared positive and a caution, not a borrowed ramp step.

  6. The monospace voice

    Every eyebrow, legend figure and footnote in the reference is monospace, and that single choice is what makes the layout feel instrumented rather than marketed. Donblas declares two families — Brandon Grotesque and Manrope — and no mono. IBM Plex Mono stands in above. Either the system adopts a third family for data, or this layout loses the quality that distinguishes it.

  7. The content shape

    The specimens above are the shipped marketing site, not invented cards, and the second one is the point: Donblas already sets four figures in a row on the navy band. The reference’s content model is a slower version of something the brand does once. Taking it into the product means keeping the copy discipline — a headline of two words, a caption of one line — and giving each figure the room the band denies it.
