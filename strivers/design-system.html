Does it repurpose?

  1. The dark ground

    Of the three systems this layout has been tested on, Strivers is the only one that can run it dark, and it is the better fit. The reference's whole effect depends on a specimen floating clear of its surround; on #111 with a #1E1E1E card and a 1px inset hairline, the separation comes from value rather than shadow, which is what this system already does everywhere else.

  2. The alternating rhythm

    Label block and specimen trading sides costs the system nothing and suits it: Strivers documents its own sections as halves, so this pacing is already the native layout, used slower.

  3. Semantic up and down

    The sharpest gap of the three. Donblas has one semantic colour, Sequoia has five, Strivers has none — eleven tokens, of which amber is the only non-neutral. You can see it in the real screens above: progress, success and the positive feedback state all resolve to the same amber, because amber is the only colour available. That works once. Put four status cards on one screen and everything is either amber or grey, which is no signal at all. This content model needs a declared positive, caution and negative before it ships.

  4. Radius and elevation as tokens

    The system tokenizes neither. The 4px corners on the cards and screen holders above were measured off specimen frames, and there is no shadow scale — dark systems rarely need one. So the card treatment framing these screens is a decision the layout made, not one the system supplied. Fine for an overview page, a real gap for a handoff.

  5. The monospace voice, by accident

    Strivers is the closest of the three to having a data face, and it did not mean to be: Menlo already appears in the source sheet setting hex labels. The plate captions and spec values above use it, and the instrumented quality the reference depends on arrives almost for free — though note the product screens themselves never do, so this would be a genuine addition. Promoting an annotation face to a product face is a small, defensible amendment — much smaller than adopting a third family from scratch.

  6. The logo construction plate

    Kept as a frame, but the content is thinner than the frame implies. The lockup ships as one flattened 414 × 171 asset with the wordmark baked in, so the grid above is illustration, not derivation, and the labels say what is true — measured radius, drawn geometry, three lockups. The wordmark itself is a bitmap in the source files, which is the known gap in this project's material.

  7. The content shape

    Rather than invent four metric cards, the specimens above are the shipped screens — weekly goal, trainer message, workout summary, post-workout feedback. They map onto the reference’s four slots almost exactly, with one substitution worth noting: where the reference puts a machine insight, Strivers puts a trainer on camera. The copy constraint is the real borrow: two words in the label, one line in the caption, one number on the screen.
